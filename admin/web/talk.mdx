# Talk realtime voice (removed)

Talk - the live browser voice conversation with WednesdayAI, with captions, natural interruption
and automatic reconnection - lived in the classic operator console's **Talk** tab. The classic
console was removed, and Talk was removed with it (ADR 1771,
`dev-docs/adr/1771-classic-console-removal-control-ui-key.md`). The
[Control UI v2](/web/control-ui-v2) console has no Talk tab.

Browser voice features still exist in the `/v2/client` [web client](/web/user-client): the
message box's **Dictate** and **Voice mode** controls. They are a separate feature with their own
instructions - see
[Using the web client](/web/using-the-web-client#dictate-and-voice) and
[Voice conversation sessions](/talk/realtime-voice-conversation).

The gateway-side realtime voice relay and its provider interface remain; other clients can still
use them. See [Realtime Voice gateway relay](/talk/realtime-voice) and
[Realtime Voice Provider API](/talk/realtime-voice-api).
