# Talk realtime voice

Talk lets you have a live voice conversation with WednesdayAI in your browser. Start
Talk, allow microphone access, and speak normally. You see live captions and can begin
your next sentence while WednesdayAI is speaking.

The current built-in browser voice service is OpenAI Realtime. The person who manages
WednesdayAI must enable Talk and connect an OpenAI API key before the **Talk** tab appears.

<Note>
This is the Control UI's **Talk** tab (an operator console). Looking for the **Dictate** or
**Voice mode** buttons in the `/v2/client` web client's message box instead? Those are a separate
feature — see [Using the web client](/web/using-the-web-client#dictate-and-voice).
</Note>

## Before you start

- Open Talk directly from the WednesdayAI Control UI address. Microphone access is
  allowed only to that page's own website address, not to a copy embedded in another site.
- Use HTTPS when connecting remotely. `localhost` and `127.0.0.1` also work locally.
- Talk uses your browser's default microphone. It does not have its own microphone picker.

## Start a conversation

<Steps>

1. Open the Control UI and select **Talk**.

   You should see **Ready to talk**. If the tab is missing, ask the person who manages
   WednesdayAI to enable Talk and its voice service.

2. Select **Start talking** and allow microphone access when your browser asks.

   You should see **Connected**, **Listening**, or **Microphone live** when Talk is ready.

3. Speak normally and listen for the reply.

   Live captions appear for both sides of the conversation. Temporary caption text may
   change as speech is recognized; final wording replaces it. Talk keeps each question
   before its answer even when the answer text arrives first.

4. Select **Stop** when you are finished.

   Talk ends the voice conversation and fully releases your microphone.

</Steps>

## Interrupt WednesdayAI

While WednesdayAI is speaking, start your next sentence. Your microphone remains live,
and recognized speech stops the queued reply. The status briefly shows **Interrupting
playback**.

Talk protects against mistaking speaker echo for your voice. An interruption in the
instant playback begins may be ignored, and microphone audio is briefly ignored for half
a second after normal playback ends. If your first words are missed, pause briefly or use
a headset.

## If the connection drops

If the Control UI briefly disconnects, Talk releases the old microphone conversation and
starts a new one when the connection returns. Captions already shown remain visible, and
new captions appear after them. Late audio and captions from the old connection are ignored.

Select **Stop** while disconnected if you do not want Talk to restart automatically.

## Status messages

| Status                         | Meaning                                                           |
| ------------------------------ | ----------------------------------------------------------------- |
| **Ready to talk**              | Talk is available, but no conversation is active.                 |
| **Starting voice session**     | WednesdayAI is connecting to the voice service.                   |
| **Connected** or **Listening** | You can speak.                                                    |
| **WednesdayAI is speaking**    | Audio is playing; you can speak to interrupt it.                  |
| **Interrupting playback**      | Talk is stopping the current reply.                               |
| **Talk unavailable**           | Talk is not enabled or its voice service is not ready.            |
| **Voice session error**        | The connection ended because the voice service reported an error. |

## Troubleshooting

### The Talk tab is missing

Wait for the Control UI to reconnect. If Talk still does not appear, ask the person who
manages WednesdayAI to enable Talk and configure OpenAI Realtime. Talk stays hidden until
both are ready.

### The browser does not ask for microphone permission

Open the browser's site settings for the Control UI, set **Microphone** to **Allow**, reload
the page, and select **Start talking** again. Open the Control UI directly rather than inside
another website, and use HTTPS for remote access.

### Talk uses the wrong microphone

Change the default microphone in your browser or operating system, select **Stop**, and
select **Start talking** again. Talk requests a fresh microphone each time it starts.

### Speech is cut off or speaker echo interrupts the reply

Use a headset, move the microphone away from speakers, and leave your browser's echo
cancellation enabled. Pause briefly before repeating words that were missed immediately
after playback.

### A conversation starts and then closes

Select **Retry** once. If it happens repeatedly, contact the person who manages WednesdayAI
and share the time the failure occurred.
