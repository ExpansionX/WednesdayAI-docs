# xAI (Grok)

xAI provides the Grok model family through an OpenAI-compatible API. OpenClaw integrates with xAI for text and vision inference. The default model is `grok-4`.

## Requirements

- An xAI API key from [console.x.ai](https://console.x.ai)

## Quickstart

```bash
openclaw onboard --auth-choice xai-api-key
```

Or non-interactive:

```bash
openclaw onboard --non-interactive \
  --mode local \
  --auth-choice xai-api-key \
  --xai-api-key "$XAI_API_KEY"
```

Then verify the default model was set:

```bash
openclaw models status
```

## Configuration

### Environment variable

```bash
export XAI_API_KEY="xai-..."
```

OpenClaw reads `XAI_API_KEY` automatically and enables the `xai` provider.

### Config snippet

```json5
{
  env: { XAI_API_KEY: "xai-..." },
  agents: {
    defaults: {
      model: { primary: "xai/grok-4" },
    },
  },
}
```

### Provider settings

| Setting                | Value                                    |
| ---------------------- | ---------------------------------------- |
| Provider ID            | `xai`                                    |
| Base URL               | `https://api.x.ai/v1`                    |
| API                    | OpenAI-compatible (`openai-completions`) |
| Auth env var           | `XAI_API_KEY`                            |
| Default model          | `grok-4`                                 |
| Default context window | 256,000 tokens                           |
| Default max tokens     | 8,192                                    |

## Web search with Grok

xAI's Grok supports live web search via the Responses API. You can configure it separately for the web search tool:

```json5
{
  tools: {
    web: {
      search: {
        grok: {
          apiKey: "xai-...", // falls back to XAI_API_KEY
        },
      },
    },
  },
}
```

The web search tool uses `grok-4-1-fast` by default when Grok search is enabled. See [Tools: web search](/tools/web) for full configuration.

## Troubleshooting

**401 Unauthorized**

- Verify your key starts with `xai-` and is copied in full.
- Re-run onboarding: `openclaw onboard --auth-choice xai-api-key`.

**Tool schema errors**

xAI rejects certain JSON Schema keywords in tool definitions. OpenClaw automatically sanitizes tool schemas for xAI — no configuration needed.

**Model not found**

- Confirm the model ID is correct and your xAI plan includes it.
- Run `openclaw models status` to see detected xAI models.
