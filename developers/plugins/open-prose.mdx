# OpenProse (plugin)

OpenProse VM skill pack with a `/prose` slash command for creative and prose writing.

## Install

```bash
wednesdayai plugins install @wednesdayai/open-prose
```

Local checkout:

```bash
wednesdayai plugins install ./extensions/open-prose
```

## What it does

- Adds a `/prose` slash command for prose/creative writing tasks.
- Ships a skill pack that enhances the agent's writing capabilities.
- Designed for creative writing, drafting, and content generation.
