# Changing settings

You can ask WednesdayAI to change a setting in chat, or you can edit settings in the Control UI (the web control panel). Small, targeted changes are the safe path. Replacing the whole settings file at once is turned off for the assistant unless the person who installed WednesdayAI turned that on.

## Change one thing in chat

<Steps>

### Ask for the specific change

Tell the assistant exactly what you want, for example: "Turn logging to info" or "Use this model for new chats."

**You should see:** the assistant confirms the change, or explains that it updated only that setting.

### If the assistant says it cannot apply or replace settings

That is expected. The assistant is allowed to make surgical updates. It is not allowed to overwrite the entire settings file by default.

**You should see:** a message that the apply action is denied, or that it will patch instead. Your existing channels, models, and plugins stay as they were.

### Try the Control UI if you need a bigger edit

Open the Control UI Config page, change the fields you care about, and save.

**You should see:** a successful save, or an error that the write was refused. A refused save leaves your previous settings in place.

</Steps>

<Tip>
Prefer one change at a time. If you are not sure, ask the person who set up WednesdayAI to make the edit.
</Tip>

## What WednesdayAI protects

- The assistant cannot wipe whole sections of settings (channels, plugins, and so on) by rewriting the file.
- If a save would remove a whole settings section you did not delete, WednesdayAI refuses the save. The file on disk does not change.
- The Control UI records which whole sections you actually removed, so an intentional delete still works.

## Troubleshooting

**The assistant cannot change a setting**

Ask it to change only that one value. If it still fails, use the Control UI or ask your administrator.

**A save said the write was refused**

Nothing was overwritten. Fix the document so it still includes the sections you did not mean to delete, then save again.

**Settings already look empty or channels disappeared**

That is from an older build, or from a manual file edit. Ask your administrator to restore the backup file next to the settings file (it ends in `.bak`) and restart WednesdayAI.

**You wanted the assistant to replace the entire settings file**

Only the person who operates the gateway can turn that on. It is off on a normal install.
