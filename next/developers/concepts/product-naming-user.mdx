# What is WednesdayAI?

WednesdayAI is the name of your personal assistant platform. When the assistant talks about the product it runs on, status lines, browser tools, or docs links, it should say **WednesdayAI** — not the older OpenClaw name.

## What you should see

- The assistant describing itself as running **inside WednesdayAI**.
- Status or version lines that start with **WednesdayAI** and a version number.
- Docs links pointing at **docs.wednesdayai.dev**.
- Browser-tool help that names the **WednesdayAI Browser Relay** toolbar icon (that is the real Chrome extension name).

## What this does not change for you

- Your chats, memories, and workspace files stay where they were.
- If you already had an assistant set up, you do not need to rename anything in chat for it to keep working.
- Your administrator still uses the same install folder and config file names behind the scenes (they may still mention `openclaw` in paths). That is normal and does not mean the product went back to the old brand.

## If the assistant still says OpenClaw

1. Ask it again after your administrator has updated and restarted WednesdayAI.
2. Start a **new** chat/session if an old conversation still quotes outdated instructions.
3. If it keeps happening, tell your administrator the assistant is quoting the old product name — that usually means the gateway is still on a pre-rename build.
