# Model Providers

WednesdayAI can use many LLM providers. Pick a provider, authenticate, then set the
default model as `provider/model`.

Looking for chat channel docs (WhatsApp/Telegram/Discord/Slack/Mattermost (plugin)/etc.)? See [Channels](/next/admin/channels).

## Quick start

1. Authenticate with the provider (usually via `wednesdayai onboard`).
2. Set the default model:

```json5
{
  agents: { defaults: { model: { primary: "anthropic/claude-opus-4-6" } } },
}
```

## Transcription providers

Audio/image/video understanding providers ship as plugin extensions, disabled by default. See
[Media Understanding](/next/users/nodes/media-understanding#provider-extensions) for the full vendor list
(OpenAI, Groq, Deepgram, Google, Mistral, ElevenLabs, OpenRouter, DeepInfra, Bifrost, and more)
and how to enable one.

- [Deepgram (audio transcription)](/next/admin/providers/deepgram)

## Streaming voice conversation providers

The live, cascaded voice conversation loop behind the `/v2/client` web client's Dictate and Voice
mode controls uses its own streaming speech-to-text/text-to-speech provider seam, separate from
the transcription providers above. See
[Voice conversation sessions](/next/users/talk/realtime-voice-conversation).

- [ElevenLabs (streaming voice)](/next/admin/providers/elevenlabs)
