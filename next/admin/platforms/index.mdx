# Platforms

WednesdayAI core is written in TypeScript. **Node is the recommended runtime**.
Bun is not recommended for the Gateway (WhatsApp/Telegram bugs).

Companion apps exist for macOS (menu bar app) and mobile nodes (iOS/Android). Windows and
Linux companion apps are planned, but the Gateway is fully supported today.
Native companion apps for Windows are also planned; the Gateway is recommended via WSL2.

## Gateway service install (CLI)

Use one of these (all supported):

- Wizard (recommended): `wednesdayai onboard --install-daemon`
- Direct: `wednesdayai gateway install`
- Configure flow: `wednesdayai configure` → select **Gateway service**
- Repair/migrate: `wednesdayai doctor` (offers to install or fix the service)

The service target depends on OS:

- macOS: LaunchAgent (`ai.wednesdayai.gateway` or `ai.wednesdayai.<profile>`; legacy `ai.openclaw.gateway`, `com.openclaw.*`)
- Linux/WSL2: systemd user service (`wednesdayai-gateway[-<profile>].service`)
