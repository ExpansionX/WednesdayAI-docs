# Chat Channels

WednesdayAI can talk to you on any chat app you already use. Each channel connects via the Gateway.
Text is supported everywhere; media and reactions vary by channel.

## Supported channels

- [A2A](/next/admin/channels/a2a) — Agent-to-agent dialogue between WednesdayAI gateways and A2A 1.0 agents (bundled plugin).
- [BlueBubbles](/next/admin/channels/bluebubbles) — **Recommended for iMessage**; uses the BlueBubbles macOS server REST API with full feature support (edit, unsend, effects, reactions, group management — edit currently broken on macOS 26 Tahoe).
- [Discord](/next/admin/channels/discord) — Discord Bot API + Gateway; supports servers, channels, and DMs.
- [Feishu](/next/admin/channels/feishu) — Feishu/Lark bot via WebSocket (plugin, installed separately).
- [Google Chat](/next/admin/channels/googlechat) — Google Chat API app via HTTP webhook.
- [iMessage (legacy)](/next/admin/channels/imessage) — Legacy macOS integration via imsg CLI (deprecated, use BlueBubbles for new setups).
- [IRC](/next/admin/channels/irc) — Classic IRC servers; channels + DMs with pairing/allowlist controls.
- [LINE](/next/admin/channels/line) — LINE Messaging API bot (plugin, installed separately).
- [Matrix](/next/admin/channels/matrix) — Matrix protocol (plugin, installed separately).
- [Mattermost](/next/admin/channels/mattermost) — Bot API + WebSocket; channels, groups, DMs (plugin, installed separately).
- [Microsoft Teams](/next/admin/channels/msteams) — Bot Framework; enterprise support (plugin, installed separately).
- [Nextcloud Talk](/next/admin/channels/nextcloud-talk) — Self-hosted chat via Nextcloud Talk (plugin, installed separately).
- [Nostr](/next/admin/channels/nostr) — Decentralized DMs via NIP-04 (plugin, installed separately).
- [Signal](/next/admin/channels/signal) — signal-cli; privacy-focused.
- [Synology Chat](/next/admin/channels/synology-chat) — Synology NAS Chat via outgoing+incoming webhooks (plugin, installed separately).
- [Slack](/next/admin/channels/slack) — Bolt SDK; workspace apps.
- [Telegram](/next/admin/channels/telegram) — Bot API via grammY; fast setup, groups, forum topics, and multi-bot polling/webhook fleets from one gateway.
- [Tlon](/next/admin/channels/tlon) — Urbit-based messenger (plugin, installed separately).
- [Twitch](/next/admin/channels/twitch) — Twitch chat via IRC connection (plugin, installed separately).
- [WebChat](/next/admin/web/webchat) — Gateway WebChat UI over WebSocket.
- [WhatsApp](/next/admin/channels/whatsapp) — Most popular; uses Baileys and requires QR pairing.
- [Zalo](/next/admin/channels/zalo) — Zalo Bot API; Vietnam's popular messenger (plugin, installed separately).
- [Zalo Personal](/next/admin/channels/zalouser) — Zalo personal account via QR login (plugin, installed separately).

## Notes

- Channels can run simultaneously; configure multiple and WednesdayAI will route per chat.
- Fastest setup is usually **Telegram** (simple bot token). WhatsApp requires QR pairing and
  stores more state on disk.
- Group behavior varies by channel; see [Groups](/next/admin/channels/groups).
- DM pairing and allowlists are enforced for safety; see [Security](/next/admin/gateway/security).
- Troubleshooting: [Channel troubleshooting](/next/admin/channels/troubleshooting).
- Model providers are documented separately; see [Model Providers](/next/admin/providers/models).
