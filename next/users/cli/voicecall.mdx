# `wednesdayai voicecall`

`voicecall` is a plugin-provided command. It only appears if the voice-call plugin is installed and enabled.

Primary doc:

- Voice-call plugin: [Voice Call](/next/developers/plugins/voice-call)

## Common commands

```bash
wednesdayai voicecall status --call-id <id>
wednesdayai voicecall call --to "+15555550123" --message "Hello" --mode notify
wednesdayai voicecall continue --call-id <id> --message "Any questions?"
wednesdayai voicecall end --call-id <id>
```

## Exposing webhooks (Tailscale)

```bash
wednesdayai voicecall expose --mode serve
wednesdayai voicecall expose --mode funnel
wednesdayai voicecall expose --mode off
```

Security note: only expose the webhook endpoint to networks you trust. Prefer Tailscale Serve over Funnel when possible.

## Logs and privacy

Voice-call webhook, media-stream, and outbound-call paths use structured subsystem logs. Production
logs include operational metadata such as call ids, stream ids, provider status, and error reasons,
but they should not include transcript text, caller messages, or generated assistant responses.

Use normal gateway log controls to inspect or retain these events:

```bash
wednesdayai logs --follow
wednesdayai logs --json
```

If you need durable voice-call call records, tune the `extensions.voiceCall.calls` profile under
`logging.fileLogs` rather than adding ad-hoc file writes in the plugin.
