# How replies arrive

A long answer from WednesdayAI may show up as one chat message or as several messages in a row. That is normal. Every chat app limits how long a single message can be, and long replies are automatically split to fit. The person who set up WednesdayAI can also choose whether each paragraph arrives separately.

## What you should see

- **One message** when the answer is short, or when the setup packs several paragraphs together.
- **Several messages in a row** when the answer is long, or when each paragraph is sent on its own.
- **Code blocks keep their formatting.** The bot avoids splitting a code block across messages; only a block larger than the chat app's size limit has to span multiple messages.

<Tip>
  If replies feel too chopped up or too long to read, ask the person who installed WednesdayAI to change how replies are split. You do not need to change anything in the chat app.
</Tip>

## If something looks wrong

<AccordionGroup>
  <Accordion title="The answer stops mid-sentence">
    Wait a moment — another message may still be arriving. If it stays cut off, tell the person who set up WednesdayAI.
  </Accordion>
  <Accordion title="I get a flood of one-line messages">
    That usually means each paragraph is being sent separately. Ask the installer to pack paragraphs together instead.
  </Accordion>
  <Accordion title="A code block is split across messages">
    Very large content can span messages because of chat app size limits. If the formatting looks broken (not just split), report it to the person who set up WednesdayAI.
  </Accordion>
</AccordionGroup>
