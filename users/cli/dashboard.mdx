# `openclaw dashboard`

Open the Control UI using your current auth.

```bash
openclaw dashboard
openclaw dashboard --no-open
```

Prints the console URL and opens it in a browser (`--no-open` prints it without opening). By
default the URL is the v2 console at the gateway root —
`http://127.0.0.1:18789/#token=<gateway token>`; the console signs in with the `#token=` fragment
and strips it from the address bar. The command copies the URL to the clipboard and, when no
browser can be opened, prints an SSH port-forward hint instead.

<Note>
The classic console is deprecated: it serves at `/classic` and is removed in the next release.
`openclaw dashboard` opens the v2 console unless `gateway.controlUiV2.enabled: false` points it at
the classic console instead.
</Note>
