# `wednesdayai dns`

DNS helpers for wide-area discovery (Tailscale + CoreDNS). Currently focused on macOS + Homebrew CoreDNS.

Related:

- Gateway discovery: [Discovery](/admin/gateway/discovery)
- Wide-area discovery config: [Configuration](/admin/gateway/configuration)

## Setup

```bash
wednesdayai dns setup
wednesdayai dns setup --apply
```
