# `wednesdayai completion`

Generate shell completion scripts and optionally install them into your shell profile.

Completion is provided for `wednesdayai` only; the legacy `openclaw` alias gets no tab completion.

## Usage

```bash
wednesdayai completion
wednesdayai completion --shell zsh
wednesdayai completion --install
wednesdayai completion --shell fish --install
wednesdayai completion --write-state
wednesdayai completion --shell bash --write-state
```

## Options

- `-s, --shell <shell>`: shell target (`zsh`, `bash`, `powershell`, `fish`). Without it, printing defaults to `zsh`, `--install` uses the shell from `$SHELL` (fallback `zsh`), and `--write-state` writes all four shells.
- `-i, --install`: write the cache script for the target shell and add a source line to your shell profile
- `--write-state`: write completion script(s) to `$OPENCLAW_STATE_DIR/completions` without printing to stdout
- `-y, --yes`: suppress the install success message

## Notes

- Shell completion scripts are cached under `$OPENCLAW_STATE_DIR/completions/wednesdayai.<zsh|bash|fish|ps1>`.
- `--install` writes the cache script itself (no separate `--write-state` step) and adds a `# WednesdayAI Completion` block to your shell profile. It exits non-zero if the profile cannot be updated.
- Profiles: zsh uses `~/.zshrc`, fish uses `~/.config/fish/config.fish`, and bash uses `~/.bashrc`, or `~/.bash_profile` when there is no `~/.bashrc`. A newly created `~/.bash_profile` also loads your existing `~/.profile`, so login shells keep its settings.
- An older `# OpenClaw Completion` block or an `openclaw completion` line in your profile is replaced automatically by `--install`, `wednesdayai doctor`, onboarding, and update.
- The zsh completion script automatically initializes completion via `compinit` if it has not already been loaded.
- Automatic installation into the profile is supported for `zsh`, `bash`, and `fish`. For PowerShell, run `wednesdayai completion --shell powershell --install`: it writes the cache and prints the exact line to add to your `$PROFILE`, for example `. "$HOME/.openclaw/completions/wednesdayai.ps1"`, or `. "$env:OPENCLAW_STATE_DIR/completions/wednesdayai.ps1"` when `OPENCLAW_STATE_DIR` is set.
- Without `--install` or `--write-state`, the command prints the completion script to stdout.
- Completion generation eagerly loads command trees so nested subcommands are included.
