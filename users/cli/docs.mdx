# `wednesdayai docs`

Search the live docs at [docs.wednesdayai.dev](https://docs.wednesdayai.dev) without leaving the terminal.

```bash
wednesdayai docs browser extension
wednesdayai docs sandbox allowHostControl
```

Each result prints a title, a link to the matching page, and a short snippet of the surrounding text.

## No query

Run `wednesdayai docs` with no arguments to print the docs site link and a search hint instead of running a search:

```bash
wednesdayai docs
```

```text
Docs: https://docs.wednesdayai.dev/
Search: wednesdayai docs "your query"
```

## How the search runs

The command calls the docs site's search tool (`mcp.search_wednesday_ai` on `docs.wednesdayai.dev`) through
`mcporter`. It picks a runner in this order:

1. `mcporter`, if it is already installed and on your `PATH`.
2. `pnpm dlx mcporter`, if `pnpm` is installed.
3. `npx -y mcporter`, if `npx` is installed.

If none of `mcporter`, `pnpm`, or `npx` is available, the command fails with an error asking you to install a
Node package runner.
