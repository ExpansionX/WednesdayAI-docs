# `openclaw docs`

Search the live WednesdayAI docs (`https://docs.wednesdayai.dev`) from the terminal.

```bash
openclaw docs browser extension
openclaw docs sandbox allowHostControl
```

Run with no query to print the docs site link and a search hint instead of
searching:

```bash
openclaw docs
```

## How it works

The command calls the docs site's search tool
(`https://docs.wednesdayai.dev/mcp.search_wednesday_ai`) through
[`mcporter`](https://www.npmjs.com/package/mcporter):

- If the `mcporter` binary is on `PATH`, it runs directly.
- Otherwise it falls back to `pnpm dlx mcporter`, then `npx -y mcporter`.
- If neither `pnpm` nor `npx` is available, the command fails with an error
  asking you to install a Node package runner.

## Output

Each result prints as a title and link, followed by a short prose snippet
pulled from the matching page (at most 220 characters). In an interactive
terminal:

```
- browser extension (docs.wednesdayai.dev/...)
  Install the Chrome extension to let agents take over your browser session...
```

When output is not a terminal (for example piped to a file), results print as a
Markdown list instead:

```
# Docs search: browser extension

- [browser extension](https://docs.wednesdayai.dev/...) - Install the Chrome extension...
```

A result whose matched page section has no prose after its heading (a
heading-only match) omits the snippet line entirely — the result still
prints its title and link, with nothing beneath it.

With no results, the command reports no results and exits normally.
