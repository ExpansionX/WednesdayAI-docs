# `wednesdayai approvals`

Manage exec approvals for the **local host**, **gateway host**, or a **node host**.
By default, commands target the local approvals file on disk. Use `--gateway` to target the gateway, or `--node` to target a specific node.

Related:

- Exec approvals: [Exec approvals](/users/tools/exec-approvals)
- Nodes: [Nodes](/users/nodes)

## Common commands

```bash
wednesdayai approvals get
wednesdayai approvals get --node <id|name|ip>
wednesdayai approvals get --gateway
```

## Replace approvals from a file

```bash
wednesdayai approvals set --file ./exec-approvals.json
wednesdayai approvals set --node <id|name|ip> --file ./exec-approvals.json
wednesdayai approvals set --gateway --file ./exec-approvals.json
```

## Allowlist helpers

```bash
wednesdayai approvals allowlist add "~/Projects/**/bin/rg"
wednesdayai approvals allowlist add --agent main --node <id|name|ip> "/usr/bin/uptime"
wednesdayai approvals allowlist add --agent "*" "/usr/bin/uname"

wednesdayai approvals allowlist remove "~/Projects/**/bin/rg"
```

## Notes

- `--node` uses the same resolver as `wednesdayai nodes` (id, name, ip, or id prefix).
- `--agent` defaults to `"*"`, which applies to all agents.
- The node host must advertise `system.execApprovals.get/set` (macOS app or headless node host).
- Approvals files are stored per host at `~/.openclaw/exec-approvals.json`.
