# Using Shohin

Shohin manages the freelance workflow: clients, projects, tasks,
invoices, and bookkeeping. Your data is visible only to you (plus
organization-shared settings your team configures together).

## Email verification links

Opening a verification link that was already used — for example when a
mail scanner fetched it before you clicked — shows "Email already
verified" instead of an error. Links are single-use for the actual
verification.

## Invoices

- Invoice numbers are unique **per user**: your `INV-0001` never
  collides with another user's. Automatic numbering always continues
  from your highest existing number.
- Tax entered in the invoice form is stored with the invoice. Editing
  an invoice shows the tax percentage implied by its stored amounts and
  preserves the stored amount when nothing changes.
- Submitting an invoice number you already used returns a clear
  conflict error instead of silently renumbering.

## Task board

While a task move is saving, other drags are held briefly
(single-flight). If a save fails, only that task returns to its
previous position.
